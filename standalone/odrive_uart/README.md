# ODrive 本地控制

根目录固件与 `standalone/odrive_uart` 共用控制代码。ESP32 读取 JY901P 并运行本地控制，电脑通过 Wi-Fi 查看状态和下发命令。控制周期目标为 10 ms。

## 启动

按根目录说明接线、烧录并打开查看器。[编译与接线](../../README.md)

单独调试控制工程时，从仓库根目录运行 `idf.py -C standalone/odrive_uart -p /dev/ttyUSB0 build flash`。若使用文本控制台，从根目录运行 `python3 standalone/odrive_uart/wifi_console.py`。查看器和控制台择一连接 UDP 3334。

ODrive 侧应提前完成硬件与电机参数配置，并启用 115200、8N1 ASCII UART。ESP32 上电时发送两轴 IDLE 和零目标，需要显式给出控制指令才能启动。

## 操作命令

| 命令 | 功能 |
|---|---|
| `limits <torque_nm> <flywheel_turns_s> <wheel_turns_s>` | 设置力矩目标上限、平衡模式飞轮转速上限、驱动轮目标转速上限 |
| `torque0 <Nm>` | 设置或更新电机 0 飞轮的力矩，单位 N·m |
| `speed1 <turns/s>` | 设置或更新电机 1 驱动轮的转速，单位圈/s |
| `zero` | 停机时保持参考姿态约 2 秒，把平衡零点保存到 ESP32 NVS |
| `gains <Kp> <Kd> <1或-1>` | 设置直立 PD 增益与飞轮反作用方向 |
| `balance` | 启动电机 0 的直立调试，电机 1 保持停用 |
| `stop` | 向两轴发送退出闭环和清零目标的请求，清除等待中的命令 |
| `status`、`stream on`、`stream off` | 查看一次状态、开启或关闭状态连续上报 |
| `reconnect` | 停机时重建 ESP32 的 UART 通信 |

尖括号内换成实车数值。每次重启后重新设置 `limits` 和 `gains`。手动模式一次控制一个电机，可更新当前目标。切换模式前先 `stop`。旧客户端可为手动命令追加 100～2000 ms 的整数时长，超时后自动发出停机请求。

**Wi-Fi 断线和关闭客户端后，ESP32 继续执行当前模式。** 停车请发 `stop` 或点「手动停机」。退出闭环后，电机机械转动可能仍会继续。

## 实车记录

| 项目 | 数值 |
|---|---:|
| 飞轮最大转速 | 25 圈/s |
| 飞轮最大力矩 | 3.6 N·m |
| 最大静态恢复角度 | 2.5° |

以上为用户提供的实车数据。2.5°记录的是车身从静止倾斜状态恢复的能力，软件倾倒停机阈值见下一节。控制器的限幅仍通过 `limits` 设置。

## 平衡调试与保护

1. 让 JY901P 的 X 向车头、Y 向左、Z 向上。按实车设置 `limits`。
2. 停机后扶稳车体到参考姿态，发送 `zero`。采样时 Roll 波动需在 0.5° 内，GX 绝对值需在 2°/s 内。该零点与电脑端显示参考分开保存，重新安装 IMU 后应重新标定。
3. 确认飞轮反作用方向，发送 `gains`，再发送 `balance`。`Kp` 单位 N·m/rad，`Kd` 单位 N·m/(rad/s)。

PD 用 JY901P 的相对 Roll 和 GX 计算力矩目标，按设置的力矩上限裁剪。飞轮编码器速度用于判断反馈是否有效和飞轮是否超速。平衡模式每 50 ms 读取编码器，反馈超过 100 ms、相对倾角超过 10°或达到飞轮速度上限时请求停机。控制中收到无效或过期 IMU 数据、UART 发送错误，或计算超时，也会请求停机。

手动模式只写目标。`UART TX complete` 表示 ESP32 发完指令，电机执行情况应在 ODrive 端确认。手动模式的实际电流和转速约束沿用 ODrive 配置。

主机测试覆盖控制计算、串口和 Wi-Fi 接口。根目录整合后的实车电机动作与稳定平衡仍需实板验证。
