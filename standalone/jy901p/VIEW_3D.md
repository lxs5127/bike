# JY901P 实时 3D 姿态

在桌面终端运行：

```bash
cd /home/lxs/esp/projects/balance_bike/standalone/jy901p
/usr/bin/python3 view_3d.py
```

先将新版固件烧录到 ESP32（从仓库根目录，激活 ESP-IDF 后）：

```bash
idf.py -C standalone/jy901p -p /dev/ttyUSB0 flash
```

如果要同时调试 ODrive，改为烧录 `standalone/odrive_uart` 工程；两个固件都支持同一个 Wi-Fi 查看器。
电脑连接热点 **BalanceBike-ESP32**，密码 **balance123**，然后运行上面的命令。
也可显式指定地址：

```bash
/usr/bin/python3 view_3d.py --wifi 192.168.4.1 --udp-port 3334
```

默认使用 **Wi-Fi UDP 192.168.4.1:3334**，不打开电脑串口，只需要 Python 3 和 Tkinter。
ESP32 目标 100 Hz 发布数据；查看器目标 100 fps 绘制，窗口右上角显示实际频率。
USB 用于烧录和启动诊断，实时传感器数据经 Wi-Fi 传输。热点不提供互联网。

关闭窗口或 Wi-Fi 断线只影响数据接收，**不会停止 ESP32 本地采集或已启动的控制，也不会自动发送停机命令**。
重新连接会恢复接收最新姿态，不回放旧数据、不重发之前的运动指令。
一个会话占用数据接收端：3D 窗口和文本控制台请择一运行。

需要文本输出时，从仓库根目录运行：

```bash
/usr/bin/python3 standalone/odrive_uart/wifi_console.py
```

3D 窗口底部的 Wi-Fi 指令栏可向控制固件输入 `status`、`zero`、`limits`、`gains` 等指令，详见 [控制工程说明](../odrive_uart/README.md)。
“手动停机”按钮明确发送 `stop`；独立陀螺仪固件只提供采集，拒绝电机控制命令。
查看器的“设为零点并保存”只保存电脑显示参考；控制固件的 `zero` 才保存 ESP32 NVS 零点。

旧串口固件仍可显式使用 `--port auto --baud 460800`，这需要 pyserial；USB 重新枚举时自动识别唯一串口。
旧日志可以使用 `--log /tmp/jy901p-live-monitor.log` 回放。本次新版固件不再持续打印该串口数据格式。

- 模型跟随传感器 Roll、Pitch、Yaw 旋转；红色端表示模块 +X 方向。
- X 红、Y 绿、Z 蓝，采用右手坐标系，世界 Z 向上。
- 左键拖动改变观察视角，滚轮缩放；“重置视角”恢复默认观察方向。
- “设为零点并保存”将当前朝向设为参考，模型、右侧 Roll/Pitch/Yaw 和角度轨迹同步归零，并保存到本机。
- 下次启动自动加载上次保存的零点，窗口右下角显示“已加载保存零点”；不会将每次上电时车体所在的姿态自动当作平衡位置。
- “显示绝对姿态”恢复模型和右侧原始角度，保留已存零点；“使用已存零点”可随时切回原来的参考。
- 切换参考会清空旧轨迹。操作不修改传感器参数，角速度和加速度继续显示实测值。
- 数据超过一秒没有更新时显示“数据已停止”，保留最后姿态。
- 底部曲线为最近姿态轨迹，各轴独立缩放；该曲线用于观察变化，不用于比较幅值。

首次使用时，先将车体扶到确认的直立参考姿态，保持静止，再点击“设为零点并保存”。
零点文件默认是本目录的 `reference_pose.json`，已通过 `.gitignore` 排除，不随代码上传。
文件保存在电脑上，关闭窗口或 ESP32 断电不会删除它；重新安装传感器或其自身姿态基准改变后需重新标定。
该文件属于可视化参考，不会自动成为单片机控制程序的标定参数。

多台车或不同安装方式可分别指定文件：

```bash
/usr/bin/python3 view_3d.py --wifi 192.168.4.1 --reference-file ./my_bike_reference.json
```

自定义零点文件应保留在本机。文件损坏或保存失败时，窗口会显示失败提示，不会自动用当前姿态替代零点。

需要查看此前保存的串口格式日志时：

```bash
/usr/bin/python3 view_3d.py --log /tmp/jy901p-live-monitor.log
```

模型使用 `Rz(Yaw) × Ry(Pitch) × Rx(Roll)`，模型和右侧相对角度均由同一个相对旋转矩阵计算，以处理安装倾斜和 ±180° 回绕。
可视化不改变驱动读数，不会过滤先前实板记录到的角速度尖峰。
