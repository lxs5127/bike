# JY901P 实时 3D 姿态

在桌面终端运行：

```bash
cd /home/lxs/esp/projects/balance_bike/standalone/jy901p
/usr/bin/python3 view_3d.py --port /dev/ttyUSB0
```

板上需运行本目录的独立 JY901P 固件。查看器使用本机已安装的 Tkinter 和 pyserial，
按 **460800** 波特率读取固件打印。模块输出、ESP32 读取与打印均设为 **100 Hz**，3D 绘制目标为 **100 fps**。
窗口右上角分别显示实测数据频率和绘制频率；显示器实际呈现帧率还取决于屏幕刷新率。
启动前先退出其他串口监视器。
关闭 3D 窗口即释放串口。

需要查看文本时，在本目录运行 `idf.py -p /dev/ttyUSB0 -b 460800 monitor`。
旧版 115200 波特率固件可通过 `--baud 115200` 连接，但仍只有旧固件的数据输出频率。

- 模型跟随传感器 Roll、Pitch、Yaw 旋转；红色端表示模块 +X 方向。
- X 红、Y 绿、Z 蓝，采用右手坐标系，世界 Z 向上。
- 左键拖动改变观察视角，滚轮缩放；“重置视角”恢复默认观察方向。
- “此刻设为参考姿态”把当前朝向作为模型参考，之后显示相对转动；不修改模块或执行硬件校准。
- “显示绝对姿态”恢复原始朝向。右侧数值始终显示传感器原值。
- 数据超过一秒没有更新时显示“数据已停止”，保留最后姿态。
- 底部曲线为最近姿态轨迹，各轴独立缩放；该曲线用于观察变化，不用于比较幅值。

如果串口监视器仍在写入此前的实时日志，也可同时显示 3D：

```bash
/usr/bin/python3 view_3d.py --log /tmp/jy901p-live-monitor.log
```

模型使用 `Rz(Yaw) × Ry(Pitch) × Rx(Roll)`，相对朝向通过旋转矩阵计算。
可视化不改变驱动读数，不会过滤先前实板记录到的角速度尖峰。
